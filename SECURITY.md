# Security Policy

This repository is an intentionally vulnerable, isolated AI security lab.

- Test only systems, models, accounts, and data you own or are explicitly authorized to assess.
- Use fictional Cyranta data and the planted fake secret only.
- Never commit real API keys, tokens, customer data, prompts containing confidential information, local telemetry, or PyRIT databases.
- Report vulnerabilities in this repository through GitHub private vulnerability reporting if enabled; otherwise contact the maintainer privately before public disclosure.
- Treat GitHub self-hosted runners as privileged infrastructure. Never run untrusted pull-request code on them.
